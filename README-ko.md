# 숙소 기준 거리 자동 계산 (서버 없는 버전)

친구들의 브라우저가 Google Maps JavaScript API의 Routes 라이브러리를 직접 사용합니다. 별도 Node 서버나 Render 서버는 필요하지 않고, GitHub Pages 같은 정적 사이트에 올릴 수 있습니다.

## 기능

- 현재 선택한 Day의 숙소 주소를 출발지로 사용합니다.
- 같은 Day에 등록된 핀 주소를 목적지로 사용합니다.
- `숙소 거리 원형`을 누르면 자동차 도로 거리와 교통량을 반영하지 않은 예상 시간이 계산됩니다.
- 계산 결과는 각 사용자의 브라우저 저장소에 저장됩니다. 거리값이 원의 반지름이 되고, 핀을 끌면 방향을 바꿀 수 있습니다.

## Google Cloud 설정

Google의 Routes Library 설정 안내에 따라 **Maps JavaScript API와 Routes API를 프로젝트에서 모두 사용 설정**합니다.

현재 만든 키는 Routes API만 허용하도록 되어 있으니 다음처럼 바꿔야 합니다.

1. Google Cloud에서 **Maps JavaScript API**를 사용 설정합니다. Routes API는 이미 켜져 있어야 합니다.
2. 사용자 인증 정보에서 이 사이트용 API 키를 엽니다.
3. **애플리케이션 제한사항**을 **웹사이트**로 선택합니다.
4. 로컬 시험용으로 `http://localhost:5500/*` 및 `http://127.0.0.1:5500/*`를 허용 웹사이트에 추가합니다.
5. **API 제한사항**은 **Maps JavaScript API**로 설정합니다. (프로젝트 차원에서는 Routes API도 사용 설정되어 있어야 합니다.)
6. `index.html`의 `YOUR_RESTRICTED_BROWSER_KEY`를 이 제한된 키로 교체합니다.
7. 공개 링크를 만든 뒤, 해당 사이트 주소도 허용 웹사이트 목록에 추가합니다. GitHub Pages라면 주소는 보통 `https://내아이디.github.io/*` 형태입니다. 실제 아이디와 주소를 사용하세요.

브라우저에서 키 문자열이 보일 수 있습니다. 웹사이트 제한과 API 제한이 적용된 키를 사용하고, 사용량/할당량도 낮게 관리하세요. 키를 채팅이나 다른 사람에게 따로 보내지는 마세요.

## 공개 링크와 데이터

파일만 올리면 되므로 GitHub Pages 같은 정적 사이트 호스팅을 사용할 수 있습니다. 서버나 `.env`는 필요 없습니다. 다만 요청은 각 브라우저에서 시작해도 Google 경로 계산 요금은 **내 Google Cloud 프로젝트에 연결된 키**로 집계됩니다. 저장되는 숙소·핀 정보는 각자 브라우저에만 있으므로, 서로 같은 메모 데이터를 공유하지는 않습니다.

## 예상 시간과 사용량

예상 시간은 실시간 교통을 반영하지 않은 자동차 경로 시간입니다. Routes Matrix는 계산한 숙소-핀 조합마다 사용량을 계산합니다. Google Cloud에서 Routes API 일일 할당량을 낮게 설정하고 사용량/결제 화면을 확인하세요.
